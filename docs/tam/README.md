# docs/tam

Không gian tạm thời (scratch space) dành cho các file làm việc tạm: kết quả truy vấn, script dùng một lần, ảnh chụp màn hình.
Sử dụng đường dẫn dạng `docs/tam/<YYYYMMDD>_<task>/`. Mọi thứ trong thư mục này ngoại trừ file README này đều đã được đưa vào git-ignore — các phát hiện thu được từ các file tạm thuộc về ticket hoặc bản ghi nhật ký tương ứng.
Tuyệt đối không lưu khóa bí mật hoặc dữ liệu của cơ quan/doanh nghiệp tại đây; thư mục này chỉ được git bỏ qua chứ không bảo đảm an toàn.
