# Navigation

Where each kind of fact lives. Consult this before guessing an endpoint, a
setting or how two modules are wired.

## Docs

| Kind of fact | Where it lives |
| :--- | :--- |
| How to run, what is implemented, layout | [README.md](../../README.md) |
| System design, data model (ERD), plugin contract, extraction policy | [docs/architecture.md](../architecture.md) |
| Cloud deployment (Render + Neon + GitHub Actions + Groq), Vietnamese | [docs/cloud-deployment.vi.md](../cloud-deployment.vi.md) |
| Dated test and build evidence for released milestones | [docs/verification.md](../verification.md) |
| Product direction, assessment, phased roadmap | [docs/product/roadmap.md](../product/roadmap.md) |
| Why something was chosen | [docs/decisions/](../decisions/README.md) |
| Repeatable procedures (no dates, no phases) | `docs/runbooks/` |
| Decided work and its log | `docs/backlog/<status>/` — see [KANBAN.md](KANBAN.md) |
| Noticed, not yet decided | `docs/ledger/<status>/` — see [LEDGER.md](LEDGER.md) |
| Scratch files, never committed | `docs/tmp/<YYYYMMDD>_<task>/` |

## Code

| Concern | Where |
| :--- | :--- |
| HTTP API (all routes) | `backend/app/main.py` |
| Settings and environment variables | `backend/app/config.py`, `.env.example`, `.env.cloud.example` |
| Data model | `backend/app/db.py` |
| Extraction pipeline (tree-sitter → spaCy → ranking) | `backend/app/extraction.py`, `backend/app/lexicon.py` |
| Import jobs, archive safety, ARQ worker | `backend/app/imports.py` |
| Remote extraction on GitHub Actions | `backend/app/cloud_jobs.py`, `scripts/cloud_extract.py`, `.github/workflows/extract.yml` |
| Spaced repetition (FSRS) | `backend/app/srs.py` |
| Practice plugins | `backend/app/plugins.py`; contracts in `backend/app/contracts.py` and `shared/plugins.ts` |
| TTS / STT / LLM / dictionary adapters | `backend/app/adapters.py` |
| Web UI | `frontend/components/workspace.tsx`, `frontend/lib/api.ts` |
| Server-side API proxy and Basic Auth | `frontend/app/api/[...path]/route.ts`, `frontend/proxy.ts` |
| Tests | `backend/tests/`, `frontend/tests/` |
| CI | `.github/workflows/ci.yml` |

`frontend/AGENTS.md` is generated by `next dev` and warns that this Next.js
version differs from training data: read `frontend/node_modules/next/dist/docs/`
before writing Next.js code.

## Commands

| Purpose | Command (from the repository root) |
| :--- | :--- |
| Backend tests | `.venv/bin/python -m pytest backend/tests -q` |
| Type check | `npm --prefix frontend run typecheck` |
| Production build | `npm --prefix frontend run build` |
| Local dev (API + web) | `.venv/bin/python scripts/dev.py` |
| Browser tests (app running) | `cd frontend && npm run test:e2e` |
| Doc links | `python3 tools/docs/check_doc_links.py` (`--fix-moves` after a move) |
| Housekeeping audit | `python3 tools/docs/housekeeping.py` |
